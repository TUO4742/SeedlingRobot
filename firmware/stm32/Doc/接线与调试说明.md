# 接线与调试说明

## 1. 已核对的硬件资源

主控为 STM32F103RCT6。电机由两片 TB6612 驱动，PS2 接收器通过板载 CH559T
转为 UART5 ASCII 数据。以下资源同时根据 PCB 网络和差速参考工程核对。

### 四轮和编码器

| 代码索引 | 车轮 | 电机口 | PWM | 方向脚 | STBY | 编码器 |
|---|---|---|---|---|---|---|
| 0 | FL 左前（原 RL） | J3 | PB11 / TIM2_CH4 | PB12、PB13 | PC15 | PC6、PC7 / TIM8，软件取负 |
| 1 | RR 右后（原 FR） | J1 | PA15 / TIM2_CH1 | PC13、PC14 | PB14 | PB4、PB5 / TIM3 |
| 2 | RL 左后（原 RR） | J4 | PB10 / TIM2_CH3 | PC8、PC9 | PC15 | PA8、PA9 / TIM1 |
| 3 | FR 右前（原 FL） | J2 | PB3 / TIM2_CH2 | PC0、PC1 | PB14 | PB6、PB7 / TIM4，软件取负 |

代码使用 X 型麦克纳姆轮约定：`+vx` 前进、`+vy` 左移、`+wz` 俯视逆时针。
纯运动目标轮速符号应为：

| 运动 | FL | FR | RL | RR |
|---|---:|---:|---:|---:|
| 前进 | + | + | + | + |
| 左移 | - | + | + | - |
| 逆时针旋转 | - | + | - | + |

### 六个三线舵机接口

每个接口的 1 脚为信号、2 脚为 7.4 V、3 脚为 GND：

| 接口 | 信号网络 | 本版本用途 |
|---|---|---|
| J9 | PA0 / TIM5_CH1 | Servo 1，使用 |
| J11 | PA1 / TIM5_CH2 | Servo 2，使用 |
| J12 | PC5 | Servo 3，使用 |
| J14 | PB0 | 新夹爪（Servo 4，TIM5_CH4内部比较软件PWM） |
| J15 | PB1 | 保留 |
| J16 | PB2 / BOOT1 | 保留，优先不要用 |

J9/J11 是原生硬件 PWM。J12/PC5 没有可直接使用且不冲突的 PWM 通道，因此
TIM5 以 1 MHz、20 ms 周期运行；更新中断拉高 PC5，CH3 内部比较到达舵机脉宽时
拉低 PC5。CH3 只作为内部比较事件，不把 PA2 配成 TIM5 复用输出，避免占用
USART2_TX。代码只打开 CC3IE 并保持 CC3E 关闭，不能用会打开 PA2 通道输出门的
`HAL_TIM_OC_Start_IT()`。TIM3 已用于 FR 编码器，不能再把 PB0/PB1 当作普通
50 Hz 舵机 PWM。

## 2. PS2/CH559 协议

数据路径为 `USB 手柄 -> CH559T -> UART5_RX/PD2`，串口参数 57600、8N1。
沿用差速参考工程的文本帧：

`HUB0_Joystick data: xNN xNN xNN xNN xNN xNN xNN xNN`

使用字段：

| 字段 | 作用 |
|---|---|
| x1 | 有效帧标识，必须为 0x01 |
| x4 | 左摇杆 X，用于连续左右平移 |
| x5 | 左摇杆 Y，用于前后 |
| x6 | 右侧左右控制；0x8F 逆时针转，0x2F 顺时针转 |
| x7 | 位图：L1=01、R1=02、L2=04、R2=08、SELECT=10 |

x2、x3、x8 在参考协议中没有可靠含义，本版本没有把它们猜成右摇杆模拟量。
十字键与左摇杆拉满共用 x4/x5，右侧按键与右控制共用 x6；v1.4 使用 SELECT
作为上下文键解决冲突。x7 改为按位解析，以保留 SELECT+肩键组合。每一行必须
完整匹配；超过 300 ms 没有完整有效帧，底盘目标归零并冻结机械臂目标。

## 3. SELECT 机械臂控制与姿态角设置

操作前先让两个摇杆和所有按键回中，再按住 SELECT，随后按功能键。进入 SELECT
模式后四轮强制停止；松开 SELECT 后必须再次全部回中，底盘才会重新解锁。

| 组合键 | 动作 |
|---|---|
| SELECT + L1 | PA0/J9 大臂顺时针点动 |
| SELECT + R1 | PA0/J9 大臂逆时针点动 |
| SELECT + L2 | PA1/J11 小臂顺时针点动 |
| SELECT + R2 | PA1/J11 小臂逆时针点动 |
| 按住 SELECT + X / B | PC5/J12 旧夹爪持续开 / 合，松开保持 |
| 按住 SELECT + Y / A | PB0/J14 新夹爪持续开 / 合，松开保持 |
| SELECT + 上 / 下 / 左 / 右 | 原 L1 / L2 / R1 / R2 四组姿态 |

同一关节的正反键同时按下时不动作，方向键斜向及跨类别组合也不动作。通信超时
只会停车并保持机械臂，不会触发开爪或收爪。肩键点动只在收到
新手柄帧时前进一步，避免串口中断后继续使用缓存按键运动。

四组姿态的代码位置是 `Robot/robot_config.h`。编辑以下 12 个值即可：

```c
ARM_POSE_L1_SERVO1_DEG ... ARM_POSE_L1_SERVO3_DEG
ARM_POSE_L2_SERVO1_DEG ... ARM_POSE_L2_SERVO3_DEG
ARM_POSE_R1_SERVO1_DEG ... ARM_POSE_R1_SERVO3_DEG
ARM_POSE_R2_SERVO1_DEG ... ARM_POSE_R2_SERVO3_DEG
```

上/下/左/右对应关系及复制自 v1.1 的当前默认值为：

| SELECT 组合键 | 姿态名 | 默认角度 Servo1/2/3 | 建议用途起点 |
|---|---|---|
| 上 | L1 | 90 / 50 / 160 | 取苗接近姿态 |
| 下 | L2 | 90 / 80 / 100 | 搬运姿态 |
| 左 | R1 | 90 / 60 / 150 | 种植接近姿态 |
| 右 | R2 | 30 / 70 / 140 | 谷仓放置姿态 |

这些只是从 v1.1 复制的待调试值，不是新机构上已经验证的安全姿态。尤其 Servo3
现在是夹爪，四个姿态里的 160/100/150/140 必须根据实际夹爪重新标定；不要在
确认机械限位前直接触发预设。开爪/收爪默认值及点动方向也在同一文件中：

```c
ARM_GRIPPER_OPEN_DEG
ARM_GRIPPER_CLOSE_DEG
ARM_BIG_ARM_CW_SIGN
ARM_SMALL_ARM_CW_SIGN
ARM_MANUAL_JOG_STEP_DEG
```

## 4. 首次上电顺序

1. 不装舵盘或断开连杆，只接一只舵机；确认它能承受接口的 7.4 V。
2. 先把 `ARM_SERVO*_MIN_DEG/MAX_DEG` 收窄到保守范围，再烧录。
3. 逐个连接 J9、J11、J12，确认 90° 中位和正方向；必要时修改
   `ARM_SERVO*_REVERSED`，再安装舵盘。
4. 将四个麦克纳姆轮架空，按本次机械换位确认 J3=FL、J2=FR、J4=RL、J1=RR。
5. 分别给很小的正目标，确认轮子物理正转时编码器反馈也为正；有一项不符就先改
   接线/符号，不能靠增大 PID 掩盖。
6. 落地依次测试：前进、左移、逆时针旋转，再测组合运动。方向错时优先检查轮序、
   麦克纳姆轮辊安装方向和电机/编码器符号。
7. 行驶中拔掉手柄或接收器，确认最迟约 300 ms 后四轮 PWM 归零。
8. 最后连接完整机械臂并低速调四组姿态；观察供电是否因多舵机同时运动而跌落。

## 5. 比赛安全

- 软件上电默认等待有效手柄帧；SELECT 按住时停车并进入机械臂组合控制。
- 行驶中按 SELECT、松开 SELECT 或通信重连后，必须让行走输入回中才会重新解锁底盘。
- PS2 失联会让底盘停车，并把机械臂目标冻结在当前角度，避免断联后继续扫动或突然回零。
- 比赛要求的醒目物理急停必须直接可靠地停止执行器，不能只依赖手柄、UART、RTOS
  或 SELECT。
- 赛前确认收拢尺寸、展开尺寸、重量、电池电压，以及只夹取规则允许部位。
- 固件不自动判断裁判开始信号或 5 分钟结束；操作员必须按裁判流程启停。

## 6. 尚需实车标定

- 三个舵机的安全角度、脉宽、反向和四组最终姿态。
- 四轮物理轮序、电机正号、编码器正号、轮径、减速比和 `L+W`。
- 麦克纳姆负载下的 PID 参数及最大前后、横移和角速度。
- 7.4 V 舵机电源在三路同时动作时的电流裕量和压降。
